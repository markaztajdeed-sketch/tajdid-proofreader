# تحليل المقالات قبل التدقيق وبعده

سكربتات لقياس ما يصحّحه المدققون فعلاً ومدى تطابق قواعد الأداة معه.
المقالات نفسها لا تُرفع إلى المستودع.

- `pair.py`: يطابق ملفات قبل/بعد حين تختلف أسماؤها، ويحوّل ملفات .doc، ويتجاوز الأزواج المتطابقة.
- `extract.py`: يقرأ ملفات Word (قبل/بعد) ويطابق الفقرات، ويكتب `pairs.json`.
- `classify.py`, `stats.py`, `quotes.py`: تصنيف التعديلات وإحصاءات عامة.
- `eval2.js`: لكل قاعدة، كم مرة تقترح تصحيحاً قبل التدقيق وبعده.
- `coverage.js`: نسبة تعديلات المدققين التي تؤديها الأداة وحدها.
- `markers.py`: لكل مقال، عدد العلامات التي تكشف الدليل أو العُرف المتّبع (شدة النسبة، التنوين، أنّ/أنَّ، علامات التنصيص، الآيات، الصلوات، ص/ط/ج، السنوات) قبل التدقيق وبعده.
- `perrule.js`: أثر كل قاعدة وحدها (موجب = تقرّب النص مما فعله المدققون).
- `measure.js`: لكل تعديل أجراه المدقق، هل فعله المحرك؟ (حسب النوع: آلي أو اجتهادي)، ولكل تصحيح من المحرك، هل وافقه المدقق؟ يقبل pairs.json فيه الحقل guide (new/old).
- `review-dump.js`: يكتب كل تصحيح يقترحه المحرك على المقالات (المقالة، الفقرة، القاعدة، الكلمة قبل وبعد، والسياق) في ملف TSV لمراجعته قاعدةً قاعدة.
- `names.js`: يستخرج الأعلام (من «الاسم (Latin)» وابن/أبو/عبد وتواريخ الوفاة) والمصطلحات، ويقارنها بالقاموس.
- `shaddalex.py`: تجربة قائمة شدّات متعلّمة مع اختبار على مقالات محجوبة.

مثال: `node analysis/eval2.js <workdir> proofreader-editor/engine.js`
