# تحليل المقالات قبل التدقيق وبعده

سكربتات لقياس ما يصحّحه المدققون فعلاً ومدى تطابق قواعد الأداة معه.
المقالات نفسها لا تُرفع إلى المستودع.

- `extract.py`: يقرأ ملفات Word (قبل/بعد) ويطابق الفقرات، ويكتب `pairs.json`.
- `classify.py`, `stats.py`, `quotes.py`: تصنيف التعديلات وإحصاءات عامة.
- `eval2.js`: لكل قاعدة، كم مرة تقترح تصحيحاً قبل التدقيق وبعده.
- `coverage.js`: نسبة تعديلات المدققين التي تؤديها الأداة وحدها.
- `perrule.js`: أثر كل قاعدة وحدها (موجب = تقرّب النص مما فعله المدققون).
- `shaddalex.py`: تجربة قائمة شدّات متعلّمة مع اختبار على مقالات محجوبة.

مثال: `node analysis/eval2.js <workdir> proofreader-editor/engine.js`
